# Winson Baring

A personal portfolio organized around what projects help people do. Built with React, Vite, TypeScript and genuine shadcn/ui components.

- **Work:** ten project stories with context, use cases and outcomes. BendMe and Resume AI include distinct interactive explanations.
- **Posts:** search, platform filtering and cross-platform story grouping. The initial entries are clearly labeled, user-authorized samples, not claimed published posts.
- **Links:** a compact home for apps and confirmed social profiles.
